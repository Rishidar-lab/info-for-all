### Confirmed-dead direct dependencies

`@electric-sql/pglite`, `postgres`, `drizzle-orm`, `drizzle-kit`, `@playwright/test`.

**Not removed from `package.json` in this pass — deliberately.** `package-lock.json`
is committed and CI runs `npm ci`, which fails on any manifest/lock mismatch.
Regenerating the lock needs `npm install`, and this build environment has a
standing rule against running `npm install` in the home tree (a stray run once
pruned ~50 packages from a shared `node_modules`). Removing them is a one-line
follow-up for a maintainer on a normal machine:

```
npm rm @electric-sql/pglite postgres drizzle-orm drizzle-kit @playwright/test
npm run verify
```

Nothing imports them, so the build and the 198 tests are unaffected by their
presence or absence — verified by re-running the full suite after the v0.6 code
changes.

`@anthropic-ai/sdk` and `openai` stay: the provider seam
(`src/lib/claims/provider/`) is a documented, intentionally-empty extension point,
and they are `optionalDependencies` (absent from a default production install).
