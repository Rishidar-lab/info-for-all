## ROOT CAUSE — why OTHER_RELEVANT dominates (measured)

Of the **311 OTHER_RELEVANT clusters**, sampling their member headlines + excerpts:

| Bucket | Count | Share of OTHER | Verdict |
|---|---:|---:|---|
| **Contains a clear govt / political signal** ("CM/govt announces/proposes/launches", "Assembly:", "bill introduced", "collector issues", "case registered", party names incl. Tamil) | **90** | **29%** | should be POLITICS — keyword list too shallow |
| Contains a finance signal, no govt ("gold rate", "tax raid", "investment scam", "GST") | 18 | 6% | should be FINANCE |
| Contains a crisis signal, no govt ("accident", "murder", "soil collapse", "weather warning") | 21 | 7% | should be CRISIS |
| Contains a sports signal | 0 | 0% | — |
| **Tamil-script title** (subset of the above / below) | **40** | **13%** | classifier is English-keyword-only — **Tamil headlines match nothing** |
| **No recognisable crisis/politics/finance/sports signal** (culture, minor crime, local infrastructure, human interest) | **183** | **59%** | genuinely OTHER — must NOT be forced elsewhere |

**Five concrete causes:**

1. **No Tamil classification.** `classifyCategory()` lowercases the title and matches English
   substrings only. All 28 Tamil-only clusters + the Tamil half of bilingual/mixed feeds hit
   **zero** keywords → OTHER_RELEVANT by default.
2. **Politics keyword list is shallow.** It misses the dominant TN-political headline shape —
   "CM / State government / Minister announces / proposes / launches / to formulate **X**",
   "Tamil Nadu Assembly: …", "Bill … introduced", "Collector issues guidelines", generic
   "scheme" / "policy", "case registered / petition", party names in Tamil script.
3. **The classifier ignores signals the pipeline already computes.** The event signature
   carries `entities` (e.g. "Tamil Nadu Assembly", "CB-CID", party names), `concepts` and
   `actions`; the cluster carries `districts`, `state`, `crisisType`. None of this reaches
   `classifyCategory()` — it only sees the raw title string.
4. **Only the cluster title is classified**, not aggregated across all member articles.
5. **Geo depth gap.** Only 43/405 clusters (11%) have a district resolved and only 20% are
   tier P0, despite 5 Tamil-Nadu-focused feeds. The v0.7 Tamil district resolver
   (`resolveDistricts`, pulli/sandhi-tolerant) is used only for the tier check in
   `enrich.ts` — it is **not** feeding `cluster.districts`, which still comes from the older
   substring-based `classifyGeo` in `live/geo.ts`.

**Realistic v0.8 target:** recover ≈ 120–140 misclassified clusters (Tamil + shallow-politics
+ finance/crisis) → OTHER_RELEVANT from ~77% to ~45–55%, **without** pushing the genuine-other
183 into wrong buckets. Measured with a hand-labelled category set (precision + recall +
confusion matrix), because a lower OTHER count with collapsed precision is not a win.
