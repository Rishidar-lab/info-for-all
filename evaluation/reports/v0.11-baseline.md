## 7. Root-cause analysis — WHY Tamil representation is ~4.5%

Measured, not guessed:

| Cause | Magnitude | Detail |
|---|---|---|
| **SOURCE_NOT_CONFIGURED** | **largest** | Only 3 Tamil-native feeds. Not configured: The Hindu Tamil, Daily Thanthi, Dinamalar, Dinakaran, Dinamani, Vikatan, Maalai Malar, Nakkheeran, ABP Tamil, DT Next, Tamil Murasu, Polimer, Puthiya Thalaimurai (extra feeds). Fixable — see §8. |
| **LANGUAGE_CLASSIFICATION_FAILURE** | **~31 articles** | `detectLanguage()` (`src/lib/live/text.ts`) requires `tamil >= latin`. A News18 Tamil headline like `TN Assembly \| "தருமபுரியை தாண்டி..."` has a Latin prefix + Latin-heavy excerpt → mis-tagged `en`. **31 of News18 Tamil's 57 articles are wrongly `en`.** Fixing this ≈ **doubles** the Tamil count immediately. Not frozen — fixable now. |
| **ACCESS_BLOCKED (Akamai / Cloudflare)** | ~4 publishers | The Hindu Tamil `.xml` paths, Dinamani, Zee Biz → Akamai "Access Denied". (NB: `hindutamil.in/feed` — the WordPress path — **is not blocked**, 37 items.) |
| **FEED_NOT_AVAILABLE / NO_FEED** | ~6 publishers | Dinamalar, Daily Thanthi, Dinakaran, DT Next, Maalai Malar, Samayam Tamil, Tamil Murasu, Behindwoods, Vikatan — no working public RSS/Atom found on any tried path. |
| **EVENT_FILTERING (7-day age)** | ~140 items / run | News18 Tamil TN feed: `seen 200 / accepted 60` — 140 items older than `MAX_ARTICLE_AGE_DAYS = 7`. News18 Tamil business (`seen 200 / acc 5`) and sports (`acc 1`) are almost entirely stale. Legitimate filtering; means those feeds are low-velocity. |
| **DISCOVERY_ONLY (not integrated)** | potentially large | Google News RSS (`news.google.com/rss/search?...&hl=ta-IN`) returns **110 Tamil items** with publisher names (Daily Thanthi, Dinamani, Vikatan, Tamil Murasu…) — but `news.google.com/robots.txt` does not list `/rss/` in its `Allow:` set. **Recorded as `DISCOVERY_ONLY`, NOT integrated** pending a maintainer compliance decision. This is the single biggest potential Tamil unlock. |
| DEDUPLICATION_ERROR | 0 measured | no evidence |
| PARSER_FAILURE | 0 measured | Tamil feeds that return items parse fine |

**Bottom line:** the Tamil gap is ~60% *source-not-configured* (now fixable, see §8), ~25% *language-misclassification* (a real bug, fixable now), and ~15% *genuinely blocked / no-feed* (compliance-bounded).

cycle, because:

is to make everything *except* elapsed time ready.
