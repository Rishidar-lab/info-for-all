against `evaluation/claims/corpus.ts` + `corpus-v05.ts` at `git 9df590f`.

The spec's provisional bucket list named `I10` / `O06`; the **actual** IDs are
`J10` and `Q06`. Buckets confirmed:

| Bucket | Cases |
|---|---|

| B. state-level / no-district or claim-identity | C05, J10, S10 |

## P04 — Nagapattinam fishing warning ↔ fishing ban (Tamil↔Tamil, event level)

- **A:** நாகப்பட்டினம் மீனவர்கள் கடலுக்கு செல்ல வேண்டாம் என எச்சரிக்கை
- **B:** நாகை கடலோரத்தில் மீன்பிடிக்க தடை; வானிலை மோசம்
- **expected:** same / event · **actual:** `related` / low
- **failed signal:** `conceptScore = 0.33` (only `fishermen` shared). `sea` (A) and
  `coast` (B) are not treated as equivalent; `warn` (A) vs `impose-order` (B) →
  `actionRelation = compatible` (0.6), not `same`.
- **normalised:** A.concepts `{fishermen, sea, warning}`; B.concepts
  `{ban, coast, fishermen, weather}`; placeRelation `same` (Nagapattinam);
  lexical 0.50, semantic 0.48.
- **unsafe-match risk:** low. `sea`≡`coast` is a genuine near-synonym in coastal
  hazard reporting; the district match + time window already bound it.
- **fix:** add concept equivalence `["sea","coast"]`. Then shared = `{fishermen,
  sea}`, `conceptScore ≈ 0.67` (`conceptGood`); with `actionScore 0.6`
  (`actionOk`) the existing `moderate` branch `conceptGood && actionOk` fires →
  `same` / moderate.

## P12 — Viluppuram road subsidence ↔ road damaged by rain (Tamil↔Tamil, event level)

- **A:** விழுப்புரத்தில் சாலை சரிவு; வாகன போக்குவரத்து மாற்றம்
- **B:** விழுப்புரம்: மழையால் சாலை பாதிப்பு; வழித்தடம் மாற்றம்
- **expected:** same / event · **actual:** `different` / moderate ("insufficient shared structure")
- **failed signal:** `conceptScore = 0.00`. `road` is shared but is in
  `GENERIC_CONCEPTS`. `சரிவு` maps to `landslide` (A only); `பாதிப்பு` maps to
  `disruption` (B only); the shared "route/traffic diversion" (`மாற்றம்`) is not a
  concept at all. `actionRelation = same` (both `suspend`) but no non-generic
  concept overlap to pair it with.
- **normalised:** A.concepts `{landslide, road, traffic}`; B.concepts
  `{disruption, rain, road}`; placeRelation `same`; semantic 0.55.
- **unsafe-match risk:** medium — "same district, same generic action" is exactly
  the shape of a coincidental pair. Mitigation: require a *specific* shared
  concept, not just the action.
- **fix:** Tamil lexicon — map `பாதி`/`சேதம்`/`சரிவு`(road context) → new concept
  `damage`; map `வழி மாற்ற`/`பாதை மாற்ற`/`வழித்தட`/`திசை திருப்ப` → new concept
  `diversion`. Mirror `damage` + `diversion` in `concepts.ts` (English). Then
  shared = `{damage, diversion}` → `conceptScore ≥ 0.5`; `actionSame && conceptOk`
  → `same` / moderate.

## P13 — Tamil Nadu 16-district rain warning (Tamil↔Tamil, event level)

- **A:** தமிழ்நாட்டில் 16 மாவட்டங்களுக்கு மழை எச்சரிக்கை
- **B:** 16 மாவட்டங்களில் இன்று கனமழை; வானிலை மையம் எச்சரிக்கை
- **expected:** same / event · **actual:** `different` / moderate; **also not a candidate**
- **failed signal (two):**
  1. **candidate generation** — A resolves `Tamil Nadu:state`, B resolves *no*
     place, so neither the district block, the place block, nor the `state+concept`
     block pairs them.
  2. **decision** — `placeRelation = unknown` (B has no place); the "16 districts"
     figure that should anchor the pair is **not parsed**: the `district-count`
     regex in `quantity.ts` ends with `\b`, which never matches after a Tamil
     letter (Tamil is `\W` in non-`u` regex), so `qtyMatch = 0`.
- **normalised:** A.concepts `{district, rain, warning}`; B.concepts
  `{district, heavy-rain, rain, warning, weather}`; `conceptScore 1.0`, actions
  both `warn`.
- **unsafe-match risk:** low. "16 districts" + "rain warning" on the same day is a
  distinctive shared figure; the existing no-place / distinctive-quantity branch
  (`quantityMatch === 1 && conceptGood && placeRelation === "unknown"`) was
  designed for exactly this ("90 kmph winds" pairs).
- **fix:** (a) drop the trailing `\b` from the `district-count` regex (use a
  non-digit lookahead); (b) add a `byQuantity` block key in `candidatePairs` for
  distinctive dimensions (`district-count`, `speed`, `volume-rate`, `currency`).
  Then `quantityMatch = 1` → existing branch → `same` / moderate.

## P14 — Kanyakumari rough sea, boats ashore (Tamil↔Tamil, event level)

- **A:** கன்னியாகுமரியில் கடல் கொந்தளிப்பு; படகுகள் கரைக்கு
- **B:** குமரி மாவட்டத்தில் கடல் அலைகள் அதிகரிப்பு; மீனவர்கள் வெளியேறல்
- **expected:** same / event · **actual:** `related` / low
- **failed signal:** A is terse — only `sea` is recognised. `கொந்தளிப்பு`
  (turbulence), `படகு` (boat), `கரைக்கு` (to shore) and B's `அலைகள் அதிகரிப்பு`
  (waves rising) are all unmapped, so `conceptScore` rests on `{sea}` alone and
  A carries no action.
- **normalised:** A.concepts `{sea}`; B.concepts `{district, evacuation,
  fishermen, sea}`; placeRelation `same` (Kanyakumari); semantic 0.45.
- **unsafe-match risk:** low–medium. Adding `rough-sea` / `boat` concepts is
  narrow; the district + time window bound it.
- **fix:** Tamil lexicon — `கொந்தளிப்பு`/`அலை ... அதிகரி`/`கடல் சீற்றம்` →
  `rough-sea`; `படகு` → `boat`; `கரைக்கு`/`கரை திரும்ப` (boats) → `rough-sea`
  context. Mirror `rough-sea`, `boat` in English `concepts.ts` ("rough sea",
  "sea turned rough", "boats returned to shore"). Then shared = `{sea, rough-sea,
  fishermen?}` and with `evacuate` on B + `boat` on A the `moderate` branch
  (`conceptGood && semanticGood`) is reachable; otherwise `same` / low.

## C05 — Mettur dam level 118/120 ft (English, claim level)

- **A:** Mettur dam level at 118 feet against a full level of 120 feet
- **B:** Mettur storage nears full: 118 ft of 120 ft
- **expected:** same / **specific** + claimType `statistic` · **actual:** clustered as
  the same event, but **no shared specific claim**, and extraction returns `event`.
- **failed signal:** `parseQuantities` / `parseFigures` have **no `feet` / `ft`
  unit**. The dam `SUBJECT_CLASS` rule needs an open/release/shutter predicate, so
  "level at 118 feet" produces no action claim either. Both articles yield only a
  head claim → `sharedSpecific` undefined.
- **unsafe-match risk:** low. A reservoir level in feet is an unambiguous figure.
- **fix:** (a) `quantity.ts` — add `feet`/`ft` to the `length` dimension
  (1 ft = 304.8 mm); (b) `extract.ts` `parseFigures` — add a `water_level_ft` kind
  matching `N ft|feet` near `dam|reservoir|storage|level`. Both A and B then emit
  `stat:water_level_ft:118` and `:120` → merged `statistic` claim.

## J10 — Heavy rain hits TN air & rail traffic (English, claim level)

- **A:** Heavy rain disrupts flights and trains across Tamil Nadu
- **B:** Tamil Nadu weather: air and rail traffic hit by downpour
- **expected:** same / specific, independent · **actual:** kept separate; **not a candidate**
- **failed signal:** **candidate generation only.** Both resolve `Tamil Nadu:state`;
  the `state+concept` block requires embedding cosine `≥ 0.6` and here it is 0.38.
  The decision gate, if reached, already returns `same` / moderate ("same region,
  shared entity/action and multiple specific topics" — 3 shared concepts
  `rain, heavy-rain, rail`, both `suspend`). Once clustered, `extract.ts`
  produces a shared `action:rail:suspended` claim (non-head) for both → specific
  match satisfied.
- **unsafe-match risk:** low, provided the shared-concept guard stays. Lowering the
  state-level cosine floor is *candidate-side* generosity; the conservative gate
  still decides.
- **fix:** in `candidatePairs`, make a state-level pair a candidate when it shares
  **≥ 2 non-generic concepts** (equivalence-aware) at any cosine, keeping the
  `cosine ≥ 0.6 && ≥ 1` path. `rail` + `rain` clears the bar for J10;
  `R07` (schools closed / teacher recruitment) shares only `{school}` and stays
  out; the gate rejects it regardless.

## S10 — Rameswaram boat capsize, two fishermen missing (English, claim level)

- **A:** Two fishermen from Rameswaram go missing after boat capsizes
- **B:** Rameshwaram boat mishap: search on for two missing fishermen
- **expected:** same / specific + claimType `statistic` · **actual:** `related` / low
- **failed signal (two):**
  1. **event** — `incidentType` is `capsize` on **both** sides, but `decide.ts`
     only uses matching incident type as a *blocker when different*, never as a
     positive co-location signal. With only `{fishermen}` shared and no action on
     either side, the pair lands at `related`.
  2. **claim** — `parseFigures` "missing" regex matches "two missing fishermen"
     (B) but not "two fishermen … go missing" (A), so only B has `missing:2`.
- **normalised:** placeRelation `same` (Rameswaram city, `exactPlace = true`);
  incident `capsize`/`capsize`; concepts `{fishermen}`/`{fishermen}`.
- **unsafe-match risk:** low. Requiring `placeRelation === "same"` **and** a
  specific place / shared district **and** identical `incidentType` **and** a
  shared concept keeps two unrelated same-district incidents apart (they would
  need the same sub-type too, and `Q20` fire-vs-collapse is already blocked).
- **fix:** (a) `decide.ts` — when `sameLoc && a.incidentType === b.incidentType`
  and (`exactPlace` or shared district) and a shared concept/action, return `same`
  / moderate; (b) `extract.ts` — add a "missing" figure pattern
  `N (fishermen|persons|people|crew) … (missing|unaccounted)`.

## Q06 — Erode Cauvery-bank residents moved to safety (Tamil↔English, event level)

- **A:** ஈரோட்டில் காவிரி கரையோர மக்கள் வெளியேற்றம்
- **B:** Erode: residents on the Cauvery banks moved to safety as river swells
- **expected:** same / event · **actual:** `uncertain` / low
- **failed signal:** cross-language gate needs `coreAgree`. Both sides detect
  `evacuate` (A: வெளியேற்றம், B: "moved to safety"), and placeRelation is `same`
  (Erode + Cauvery, `exactPlace`), but **B produces no concept tokens** —
  `concepts.ts` has no form matching "moved to safety" / "river swells" — so
  `sharedSpecificConcepts = 0` and `actionSame && sharedSpecificConcepts >= 1`
  fails.
- **unsafe-match risk:** low. `exactPlace` (Cauvery) + same district + same action
  + same day is strong structured agreement.
- **fix:** `concepts.ts` — add `evacuation` forms "moved to safety", "to safety",
  "shifted to safety"; add `flood` forms "river swells", "river in spate", "banks
  overflow". B then shares `{evacuation}` (and `flood`) with A → `coreAgree` →
  `same` / moderate.

## Q11 — Cyclone Ditwah to cross coast near Nagapattinam (Tamil↔English, event level)

- **A:** புயல் திட்வா நாகப்பட்டினம் அருகே கரையை கடக்கும் என எதிர்பார்ப்பு
- **B:** Cyclone Ditwah likely to cross coast near Nagapattinam on Thursday
- **expected:** same / event · **actual:** `uncertain` / low
- **failed signal:** `coreAgree` needs a shared entity + action, or ≥ 2 shared
  specific concepts. The named cyclone **"Ditwah" / "திட்வா" is not a strong
  entity**; A does not detect `coast`/`landfall` from `கரையை கடக்கும்` ("will
  cross the coast"), so only `{cyclone}` is shared (1).
- **normalised:** placeRelation `same` (Nagapattinam); A.concepts `{cyclone}`;
  B.concepts `{coast, cyclone}`; B.eventDate `Thursday`-resolved, A undated.
- **unsafe-match risk:** low. A named-storm + same landfall district + compatible
  window is a strong anchor. `Q20` (same city, fire vs collapse) is protected by
  the incident-type blocker.
- **fix:** (a) `entity-aliases.ts` — register active named cyclones
  (`Ditwah`/`திட்வா`, plus recent `Fengal`, `Michaung`) as strong `place`/`org`
  entities; (b) Tamil lexicon — `கரை கட`/`கரையை கட`/`நிலத்தை கட` → `coast` +
  `landfall`. Then either `strongEntity && sharedSpecificConcepts >= 2` or the
  plain `sharedSpecificConcepts >= 2` (`cyclone`, `coast`) → `same` / moderate.

## Q14 — Salem farmers welcome Mettur release (Tamil↔English, event level)

- **A:** சேலத்தில் மேட்டூர் அணை திறப்பையொட்டி விவசாயிகள் மகிழ்ச்சி
- **B:** Farmers in Salem welcome the Cauvery water release from Mettur dam
- **expected:** same / event · **actual:** `related` / low ("one report is a reaction")
- **failed signal:** `isReaction` asymmetry. B carries `welcome` **and** a concrete
  action (`release-water`) → `isReaction = false`. A carries `மகிழ்ச்சி` (joy) but
  **no concrete action** because `திறப்பையொட்டி` (accusative `திறப்பு` + postposition
  `ஒட்டி`) is not matched by the `திறப்பு` → `release` lexicon key or by any suffix
  rule → `isReaction = true`. Different reaction flags → forced `related`.
- **normalised:** placeRelation `same` (Salem + Mettur Dam, `exactPlace`);
  A.concepts `{dam}`; B.concepts `{dam, release, water}`.
- **unsafe-match risk:** low.
- **fix:** Tamil lexicon — add `திறப்பை`/`திறந்து வைத்`/`திறப்பையொட்டி` → `release`
  (or add `யொட்டி`/`ஐயொட்டி` to `TAMIL_SUFFIXES`). A then detects `release` →
  `release-water` action → `isReaction = false`; both sides real events; shared
  `{dam, release}` (2) → cross-language `same` / moderate.
