# v0.12 — Productization Release Candidate

**Base:** `main` @ `e03427b` (v0.11.0) · **Branch:** `feat/v0.12-productization`
**Net diff:** 94 files, +3,325 / −3,908 · 4 npm packages removed, 10 components removed.

This release did **not** rebuild IFFA. The v0.11 evidence engine — native briefs,
the hallucination firewall, source-family independence, primary-record research,
event identity, the frozen claim engine — is unchanged and byte-identical where
it was frozen. v0.12 rebuilt the **product surface** around it and cleaned the
repository.

Audits this release is measured against:
[UI baseline](../audits/v0.12-ui-baseline.md) ·
[performance](../audits/v0.12-performance.md).

## 1. Product

### Home & feed

- **One card component.** `components/feed/FeedCard` (from a flat `FeedItem`
  projection) replaces `iffa/EventCard` (369 lines that stacked up to eight
  metadata paragraphs, raw classifier reasoning — *"Politics (strong, score
  3.5): 'ysrcp' in excerpt"* — and raw clustering tokens — *"q:inr:1200"* — onto
  every card) **and** `media/StoryCard`. The card hierarchy is now: what ·
  headline · IFFA brief (or an honest withheld line) · what changed (plain
  language) · who reported it & how independent · evidence counts · one action.
  Model reasoning and the factor table live on the story page.
- **Progressive loading.** List pages server-render ~18 cards; a client
  `<LoadMore>` appends further matching cards from `/data/index/latest.json`
  (fetched once, on click). No-JS readers get the first page + the section header
  + a link to `/trends`.
- **Compact masthead.** The "not an emergency service" disclaimer moved to the
  footer (it does not need to head every page); the healthy data-state banner is
  one line.

### Story page

Kept — it was already the strongest surface. Small changes: breadcrumb
"Top stories" → "Home"; an analytics beacon (no-op by default).

### Navigation

- A real mobile disclosure menu (`components/site-nav.tsx`): the reader
  destinations (Home · Tamil Nadu · India · Crisis · Politics · Finance · Sports
  · Trends · Search) and a separate "Transparency & tools" group (Media
  landscape · Sources · Compare · Methodology · Quality · Diagnostics).
- `aria-current="page"` on the active link; the header collapses to logo + Menu
  below `md`.
- Footer nav rebuilt into "Read" / "Understand" columns + a GitHub project
  contact line.

### Accessibility

- Global `:focus-visible` ring (was browser-default, invisible in places).
- `prefers-reduced-motion` guard.
- `.tap` 44px hit-area helper for small controls.
- No horizontal overflow at 320–1440px on any route (held from baseline).

### Correctness

- **Every in-scope cluster (763, up from 156) now has a `/story` page.** This
  fixes a real dead internal link — `/story/treasury-bills-full-auction-result-…`
  was routable but unbuilt, so a card linking it 404'd — and makes every story
  deep-linkable. `generateStaticParams` is now "has a slug and is in scope",
  not a hand-maintained union of feed queries.
- **Every page fully server-renders again.** Removing `app/loading.tsx` drops the
  route-level Suspense boundary that was pre-rendering a JS-only `<!--$?-->`
  "Loading…" shell into `<main>` on every page — this affected production too.
- `novelty.ts` keeps normalised `q:*` clustering tokens out of the reader-facing
  "what changed" string.

## 7. Honest remaining limitations

- **Coverage breadth.** ~36 feeds. 96% of routable clusters have exactly one
  genuine independent newsroom — not a clustering miss, an ingestion limit. The
  Coverage Discovery track (branch `feat/milestone-b3-discovery`) addresses this.
- **Stance / framing not calibrated.** No user-facing bias/orientation rating
  until they are — or they are removed.
- **Home is still ~18,000 px on mobile.** Six sections, each with "Load more".
  Acceptable, not minimal; a future pass could collapse Watching/Background.
- **Deploy size 170 MB.** Fine now; if it becomes a constraint, prune RSC
  payloads rather than un-linking stories.
- **No CWV numbers.** Needs a lab run post-deploy.
- **Perspective Compare v2, the source-difference matrix redesign, and a
  100-example labelled discovery eval** were scoped out of this release.

## 8. Is this v1.0?

**No.** v1.0 needs, verified in *live* operation over time:

1. Coverage discovery shipped — a single-newsroom story that has wider coverage
   should usually find a second genuine independent source.
2. Stance calibrated to a documented standard, or removed from the model.
3. Core Web Vitals measured and green on a mid-range mobile device.
4. Production monitoring (the scheduled ingest + deploy) observed stable across
   many cycles.
5. The gold corpora grown past their current small sizes with held-out splits.

v0.12 is an **excellent, honest, shippable Release Candidate**. It is not v1.0.
