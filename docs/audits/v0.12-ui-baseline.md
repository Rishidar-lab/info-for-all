## 4. Card design (Phase 2, Phase 4)

`iffa/EventCard` (`components/iffa/event-card.tsx`, 369 lines) renders, per card, up to:

- a corner number with no visible label — the raw editorial/trend score (e.g. `76`) — `event-card.tsx:128–132`
- **raw classifier debug as body copy:** `"Politics (strong, score 3.5): \"ysrcp\" in excerpt; an alert/warning used as a political-economic metaphor."` — `event-card.tsx:343–351` (`ed.reasons`) — this is internal signal decomposition on a reader-facing card
- **raw token notation:** `What changed: MAJOR new figure(s): q:inr:1200, 20 lakh` — `event-card.tsx:225–236` (`novelty.changes[0]`)
- "N source families · M reports · K syndicated" — then, separately, `"Tamil Nadu (P0) relevance · N independent source families"` again from `ed.reasons` — the same fact twice
- up to 8 further conditional paragraphs: In this thread / On the ground / finance event / sports event / one-sided so far / local-impact scale / political-thread links — `event-card.tsx:225–336`

`media/StoryCard` is closer to the target hierarchy (headline → micro-brief → SOURCES count → alignment bar → evidence line → blindspot → compare link) but still stacks 5+ metadata blocks and repeats the source count three times (`event-card` heading, "Compare N sources", metadata line).

**Target hierarchy** (Phase 2): headline → concise IFFA brief → what changed → evidence/source context → one action. Neither card is there; `EventCard` is furthest.

## 6. Performance baseline (Phase 6)

Measured from `out/` (raw bytes, and `gzip -c | wc -c`):

| Route | raw HTML | gzipped |
|---|---:|---:|
| `/` | 418,703 B | 38.0 KB |
| `/india` | 1,054,627 B | 51.1 KB |
| `/tamil-nadu` | 1,045,358 B | 45.2 KB |
| `/crisis` | 708,525 B | 33.4 KB |
| `/politics` | 710,358 B | 35.4 KB |
| `/trends` | 487,121 B | 29.4 KB |
| `/landscape` | 75,698 B | 12.2 KB |
| `/search` | 18,257 B | 4.1 KB |
| `/story/…` (typical) | 73–140 KB | 13–20 KB |

- Total client JS in `out/_next/static`: **728 KB across 15 files**; largest three chunks 229 KB / 165 KB / 113 KB (React + framework + Next runtime). Shared JS is not the problem — **server-rendered HTML volume is**.
- `<Link>` prefetch: on `/landscape`, `/india`, `/tamil-nadu` the page fires so many prefetch requests it never reaches Playwright `networkidle` within 30 s. Hundreds of `__next…__PAGE__.txt` / `_tree.txt` requests per navigation.
- No Lighthouse / CWV numbers are claimed here — none were measured. v0.12 will measure HTML size, JS size, and data-shard size before/after in `docs/audits/v0.12-performance.md`.

## 7. Correctness / links (Phase 11, Phase 12)

No uncaught console exceptions, no failed first-party asset loads, no 404s on document navigations were observed. The `ERR_ABORTED` entries in the console are cancelled `<Link>` prefetches (benign).

## 8. Accessibility (Phase 4)

| Finding | Evidence |
|---|---|
| Positive: no horizontal overflow at 320 px anywhere; `prefers-color-scheme` handled; native `<details>` used for progressive disclosure. | Playwright overflow probe |
| Many interactive targets < 32 px tall. Home mobile: **131** `<a>`/`<button>` elements under 32 px; `/india` mobile 94; `/tamil-nadu` 80. Most are inline text links and pills, but the header nav links and the citation `[n]` buttons are genuine failures. | Playwright bounding-box probe |
| Citation `[n]` chips in the Brief are `text-[10px]` `align-super` `<button>`s — below any reasonable touch target and low-contrast against `surface-2`. | `brief.tsx:213–229` |
| No visible global `:focus-visible` treatment in `globals.css` — focus rings are browser-default and disappear against the paper background in places. | `globals.css` (no focus rule) |
| Header/nav links have no `aria-current` for the active page. | `site-header.tsx` |

Contrast: `--ink-3` (#736e64) on `--surface-2` (#fbfaf6) ≈ 4.9:1 — passes AA for normal text but is used at 11 px in many places (label/metadata), where it is uncomfortable. To be checked properly during implementation.

## 10. Prioritised plan for v0.12

**Tier 1 — product surface**
1. Mobile navigation: a real disclosure menu; primary = Home · Tamil Nadu · India · Crisis · Politics · Finance · Sports · Trends · Search; utility (Sources · Landscape · Methodology · About · Diagnostics) in a secondary group / menu section; `aria-current`.
2. Home: compress the masthead to one screen of intent + status; unify on **one** card component; progressive loading (server-render a first page, "Load more" hydrates from the `/data/index` shard).
3. One card component: headline → 1–2 line brief (or honest withheld line) → "what changed" (plain language, no tokens) → "N sources · M independent families · Tamil x · English y" → evidence chip → one action. Classifier reasoning and factor tables move to the story page / a `<details>`.
4. List pages: server-render ~12–20, "Load more" for the rest; drop `showWhy` from card default.
5. Fix the `treasury-bills…` dead link (make `generateStaticParams` and the card link agree).
6. PWA manifest: real 192/512 icons.
7. Accessibility: global `:focus-visible` ring; enlarge citation chips and nav tap targets; `aria-current`.

**Tier 2 — repo & docs**
8. Move milestone reports → `docs/releases/archive/`; fix links.
9. Remove dead deps (`pglite`, `drizzle-orm`, `postgres`, `drizzle-kit`) and dead components after a second proof-of-non-use.
10. README rewrite (current release, real screenshot, architecture diagram, evidence philosophy, run/test, privacy, limitations, roadmap).
11. `docs/CASE-STUDY.md`, `docs/PRODUCT-METRICS.md` + analytics abstraction (no-op default), `docs/COMMERCIAL-READINESS.md`.
12. `docs/audits/v0.12-performance.md` (before/after).

**Tier 3 — release**
13. Version → `0.12.0`; full regression (`lint`, `typecheck`, `test`, `test:e2e`, all `eval:*`, `quality-gate`, `build`); new regression tests (mobile nav, load-more, withheld state, 320 px overflow, analytics no-op).
14. Commit in logical chunks, push, PR, deploy via the existing Pages workflow, verify the live URL.
15. `docs/releases/v0.12-productization.md` + terminal summary.

**Explicitly deferred to a later pass** (documented, not attempted): Perspective Compare v2 / source-difference matrix redesign (Phase 16–17), a 100-example labelled discovery eval (Milestone B.3 Phase 20), Media Cloud / external search adapters, a paid analytics provider. The Milestone B.3 coverage-discovery work continues on its own branch (`feat/milestone-b3-discovery`).
